AI-powered email assistant for restaurants

🍽️ AI Restaurant Email Agent

Automatically reply to reservations, respond thoughtfully to feedback, and send smart coupons – directly from your Gmail inbox.

✨ What it does

  • Reads your Gmail inbox using the Gmail API (OAuth, no password sharing).
  • Understands whether an email is about a reservation, feedback, or something else.
  • Auto-confirms reservations or asks politely for missing details.
  • Analyzes feedback tone (happy / neutral / upset) using OpenAI.
  • Sends personalized replies with unique coupon codes (5–40% off) to win guests back.
  • Stores all coupons in a local SQLite database for later tracking.

🧩 Requirements

  • Python 3.10+
  • An OpenAI API key (e.g. sk-...)
  • A Gmail account for your restaurant (e.g. yourrestaurant@gmail.com)
  • A Google Cloud project with the Gmail API enabled + client_secret.json
  • Basic terminal / command line access

🛠️ Setup (quick version)

  1. Clone the GitHub repo: 
    git clone https://github.com/pranayreddy241/Email_Reply.git
cd Email_Reply
  2. Create a .env file: 
    OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
TIMEZONE=America/New_York

EMAIL_ADDRESS=your@gmail.com
EMAIL_PASSWORD=your-app-password

RESTAURANT_NAME="Rain's Restaurant"
RESERVATION_PHONE="+1-555-123-4567"
RESERVATION_LINK="https://yourbookinglink.com"
AGENT_DB_PATH=email_agent.sqlite

USE_GMAIL_DRAFTS=false
  3. Download client_secret.json from Google Cloud and place it in the project root.
  4. Run the installer: 
    ./install.sh
  5. Start the agent: 
    source venv/bin/activate
python3 agent.py
  6. Start the coupon dashboard: 
    streamlit run dashboard.py

🎟️ Coupons & Sentiment

The agent stores each feedback reply as a row in a local SQLite table coupons:

  • email guest email
  • code coupon code like CARE30-AB12X
  • discount % off (5–40)
  • sentiment positive / neutral / negative
  • score upset score (1–5)
  • created_at timestamp

You can open the email_agent.sqlite in any SQLite viewer, or use the built-in view_coupons.py or the Streamlit dashboard to explore and export your data.
